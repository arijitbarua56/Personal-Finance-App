Cloud behavior:
- Uses Supabase email + password sign-in directly inside the PWA.
- If the signed-in user has NO finance_state row, the first signed-in device uploads its local copy.
- If cloud data exists, every other signed-in device downloads it automatically.
- While the app is open, it refreshes from cloud every ~20 seconds and whenever the app/browser regains focus.
- Every local change automatically uploads to cloud after a short delay.

IMPORTANT:

Authentication > Providers > Email
- Email provider: ON
- Confirm email: OFF (recommended for this private app)

6. The Home Screen app should upload the fresh starting copy if cloud is empty.
